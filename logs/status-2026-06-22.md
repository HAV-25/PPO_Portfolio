### How the pipeline works

1. **CWA-v2 fires at 09:00 UTC** — reads next scheduled topic from Google Sheet Calendar tab, runs 4 web searches, writes MDX article + LinkedIn post, updates Articles tab (`qa_status=draft_pending_qa`, `status=draft_submitted`), pushes draft to `content/draft/[slug]` branch. Does NOT send email.
2. **EQA fires at 09:30 UTC** — reads draft cold from GitHub, runs 15-point checklist (11 CWA criteria + 4 cold-read items), revises if 1–4 items fail (max 2 revision cycles), commits final article to `content/[slug]` branch if passed, creates Gmail draft via Gmail MCP, escalates via Gmail draft if unfixable.

### State bus

Google Sheet `1iNPzPaQetRZh9QrUDsaYSW5NYrX9GcR3HbeXIpWAxX4` — Articles tab columns A–S:
- `qa_status`: `draft_pending_qa` → `qa_revision_in_progress` → `qa_passed` → `qa_failed_escalated`
- `status`: `draft_submitted` → `awaiting_approval` → `deployed` (manual)
- `draft_branch`: set by CWA-v2, read by EQA
- `eqa_notes`: full 15-point checklist results written by EQA
- `revision_count`: incremented per EQA revision cycle
