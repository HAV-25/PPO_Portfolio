## Pipeline architecture (complete as of today)

```
CWA-v2 (09:00 UTC Mon–Thu)
  → writes raw MDX to content/draft/[slug] branch
  → updates Sheet: qa_status=draft_pending_qa

EQA (09:30 UTC Mon–Thu)
  → QA evaluates + up to 2 revision cycles
  → PASS: commits to content/[slug] branch
  → updates Sheet: qa_status=qa_passed, status=awaiting_approval
  → Gmail draft: [Content Ready] with APPROVE / REJECT buttons (Netlify URLs)

Payal clicks APPROVE
  → https://ppo-personal.netlify.app/api/content/approve?token=X&action=approve&slug=X
  → validates token, merges content/[slug] → main
  → updates Sheet: status=approved_pending_cda
  → triggers CDA via HTTP POST (trig_01Vdvi3xpksVJGfNwzFNuAuh)
  → returns "Formatting in progress" page to Payal

CDA (fires on webhook)
  → reads content/insights/[slug].mdx from content/[slug] branch
  → generates DALL-E 3 hero image → public/images/insights/[slug]-hero.png
  → injects heroImage into MDX frontmatter, sets status=approved
  → commits formatted files to content/[slug] branch
  → merges content/[slug] → main via GitHub API
  → POSTs to Netlify Build Hook → site rebuilds (~3 min)
  → updates Sheet: status=deployed, production_url=https://ppo-personal.netlify.app/insights/[slug]
  → Gmail draft: [Published] with LinkedIn post ready to copy
```
